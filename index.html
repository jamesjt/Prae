Childhood skills, 4 skill points:
- 1 must be used to increase a Physical skill to Basic Rank.
- 1 must be used to increase a Mental skill to Basic Rank.
- 1 must be used to increase a Social skill to Basic Rank.
- 1 can be used at player's discretion.
Training skills, 5 skill points:
- 1 must be used to increase a P,M or S skill to Basic Rank.
- 1 must in a different category than above.
- 1 can be used at player's discretion
- 3 must be used to increase a skill with Basic to Trained Rank
Select a Way.
- Increase the Way's attack skill Rank to 3:Trained
- Learn the Talent and Foci related to your Way
Gain 5 Ability Points
- 1 must be used on for a Talent
- 1 must be used for a Foci
- 2 must be used for a Arcana
- The remaining 1 can be used at player's discretion
For each attack skill of basic and above gain 1 proficiency point in that skill.
- For each proficiency point in Strikes or invokes learn one Critical Effect
- For each proficiency point in Blasts learn an additional String
Assign Attributes
- Select Primary Attribute. Assign it a value of 2.
- Select Secondary Attribute. Assign it a value of 2.
- Select Tertiary Attribute. Assing it a value of 1.
- Distribute attribute points into sub-attributes (Priamry: 3, Secondary: 2, Tertiary 1)
Purchase Starting Gear
- Select 1 Weapon for free
- Learn 1 Ritual you can cast for free
- Purchase additional gear with 150 starting g.
